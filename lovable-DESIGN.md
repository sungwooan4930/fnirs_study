# Design System: Lovable

## 1. Visual Theme & Atmosphere

The interface radiates modern confidence through its bold gradient hero that transitions from electric blue to vibrant pink, creating an energetic yet professional first impression. The rest of the design breathes through generous whitespace and clean typography, establishing trust and clarity. The overall mood balances creative energy with technical precision, perfect for an AI development platform.

The design uses minimal elevation with subtle shadows on cards and components. The gradient hero creates the primary visual depth, while the rest of the interface maintains a flat, clean aesthetic with gentle layering through background color variations.

Rounded corners are used consistently across interactive elements with medium radius values. The design favors clean rectangular shapes with soft edges. Icons appear to be simple and outlined, maintaining the minimal aesthetic throughout the interface.

## 2. Color Palette & Roles

**Primary Foundation:**
- Electric Blue (#1f55f1) — primary
- Sky Blue (#4e92ff) — secondary
- Bright Blue (#486eff) — accent

**Neutral & Surface:**
- Warm Cream (#fcfbf8) — background
- Soft Silver (#d8d8d6) — border

**Text & Content:**
- Charcoal Black (#1c1c1c) — text
- Slate Gray (#5f5f5d) — text

## 3. Typography Rules

**Camera Plain Variable** (custom), **Roboto Mono Variable** (custom), **Cambria** (custom)

- **heading-1**: Camera Plain Variable, ui-sans-serif, system-ui, sans-serif 20px/30px, weight 400 — Page titles
- **heading-2**: Camera Plain Variable, ui-sans-serif, system-ui, sans-serif 48px/48px, weight 600 — Section headings
- **heading-3**: Camera Plain Variable, ui-sans-serif, system-ui, sans-serif 36px/39.6px, weight 600, letter-spacing: -0.9px — Sub-section headings
- **body**: Camera Plain Variable, ui-sans-serif, system-ui, sans-serif 16px/24px, weight 400 — Base body text
- **body-text**: Camera Plain Variable, ui-sans-serif, system-ui, sans-serif 20px/25px, weight 400 — Paragraph text
- **inline-text**: Camera Plain Variable, ui-sans-serif, system-ui, sans-serif 16px/24px, weight 400 — Inline text elements
- **link**: Camera Plain Variable, ui-sans-serif, system-ui, sans-serif 16px/24px, weight 400 — Hyperlinks
- **button**: Camera Plain Variable, ui-sans-serif, system-ui, sans-serif 14px/21px, weight 400 — Button labels
- **navigation**: Camera Plain Variable, ui-sans-serif, system-ui, sans-serif 16px/24px, weight 400 — Navigation text

## 4. Component Stylings

* **gradient-hero:** Large hero section with blue-to-pink gradient background, centered white text, and prominent search input with rounded corners
* **primary-button:** Dark rounded buttons with white text, likely using the primary brand color with hover states
* **search-input:** Large rounded input field with subtle border, placeholder text, and integrated search icon
* **logo-grid:** Clean grid layout displaying partner/client logos in grayscale with consistent spacing
* **feature-card:** Clean cards with subtle shadows, rounded corners, and organized content hierarchy
* **nav-link:** Simple text-based navigation links with hover states, no borders or backgrounds

## 5. Layout Principles

Content is centered with generous margins and consistent vertical rhythm. The layout uses a clear grid system with ample whitespace between sections, creating breathing room that enhances readability and focus. Major content blocks maintain consistent spacing patterns.
