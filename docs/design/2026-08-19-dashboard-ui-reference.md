# 대시보드 UI 참고자료 — Swiss/에디토리얼 무채색

**날짜:** 2026-08-19
**출처:** 사용자가 대화 중 제시한 목업 이미지 (`cogni·sys — cognitive performance`)
**성격:** **참고자료다. 스펙이 아니다.** 목표 4(XAI 교수자 대시보드) 착수 시 미감의 출발점으로만 쓴다.
**관련:** `CLAUDE.md` §9.2-5 (대시보드 스택 미확정), 연구계획서 목표 4

---

## 1. 채택할 미감

| 요소 | 내용 |
|------|------|
| 색 | 무채색 기본. 검정 pill 버튼만 강조 |
| 보더 | 헤어라인, 1px 그리드 분할 |
| 여백 | 큼. 밀도보다 숨 쉴 공간 우선 |
| 타이포 | 소문자 대형 헤드라인, 라벨은 small-caps |
| 레이아웃 | 헤더 / 2단 본문 / 3분할 푸터 통계 |
| 링크 | 우상향 화살표(↗)로 드릴다운 표시 |

**왜 이 방향이 이 프로젝트에 맞나:** 배경이 무채색이면 **색을 신호에만 쓸 수 있다.**
HbO/HbR 발산 컬러맵(청↔백↔적), 위험 구간 하이라이트, 6차원 중 임계 초과 차원 표시가
장식과 경쟁하지 않는다. 연구용 대시보드에서 이건 미감 문제가 아니라 판독성 문제다.

---

## 2. ⚠ 정보 구조는 그대로 쓰면 안 된다

목업의 정보 구조는 계획서 목표 4와 **대상·차원·설명가능성 세 축 모두에서 어긋난다.**

| 목업 | 계획서 목표 4 |
|------|--------------|
| **학습자 본인용** 자기 모니터링 (sessions 124, streak 14 days, total study time) | **교수자용** — 다수 학습자 동시 모니터링, 집단 분포 |
| `efficiency index 84.2%` — **1차원 스칼라** | **6차원 벡터** (인지부하·주의·피로·몰입·수행정확도·반응지연) |
| `current status: optimal` — **판정만 제시** | **판정 근거 제시**: "전전두엽 HbO 23% 증가(기여도 0.41), α/θ 비율 저하(0.28), 반응시간 증가(0.18)" |
| XAI 표면 없음 | **SHAP·어텐션 기여도가 화면의 중심** |
| 교수전략 없음 | 전략 제안 + **수용 / 수정 / 거부** 컨트롤 (자동 실행 금지) |
| 위험 구간 없음 | 임계 초과 자동 감지, **교수자가 임계치 조정 가능** |

### 가장 위험한 지점

`efficiency index 84.2%`라는 **단일 지표는 폐기된 4채널 집중도 측정기가 하던 바로 그것**이다.
`CLAUDE.md` §10이 명시적으로 금지한다 — "1차원 집중도 지수를 6차원 벡터 대용으로 사용" 금지.
목업 레이아웃을 그대로 옮기면 폐기한 자리로 되돌아간다.

`current status: optimal`도 같은 계열의 문제다. 계획서 목표 4의 핵심은 **AI가 왜 그렇게
판단했는지를 교수자가 이해·검증·수정할 수 있게 하는 것**이다. 근거 없는 판정어는 그 반대다.

## 3. 미감은 살리고 구조는 바꾸는 매핑

| 목업의 자리 | 대체 |
|------------|------|
| `efficiency index` 원형 게이지 | 6차원 레이더, 또는 6개 스몰멀티플 스파크라인 |
| `analysis results` 링크 목록 | SHAP 기여도 바 차트 (특징별, 부호 있는 값) |
| `current status: optimal` | 근거 문장 + 트리거된 교수전략 카드 |
| 푸터 3분할 통계 (sessions/streak) | 학습자 수 · 위험 구간 학습자 수 · 최근 갱신 시각 |
| 우상향 화살표 드릴다운 | 유지 — 학습자 개인 뷰로 진입 |

푸터의 small-caps 라벨 + 큰 수치 조합은 그대로 쓸 만하다. 다만 표시할 값이
**참여도(engagement metrics)가 아니라 인지상태·위험 신호**여야 한다.

## 4. 아직 결정하지 않은 것

- **대시보드 스택** (`CLAUDE.md` §9.2-5): React+FastAPI(WebSocket) vs Streamlit/Dash. 미확정.
- 실시간성 요구 수준 — 계획서는 "실시간 시각화"라고만 명시. 갱신 주기 미정.
- 한 화면에 몇 명까지 표시할지 (계획서: 평가는 교수자·전문가 10~15명 대상, 학습자 수는 별개)
- 6차원을 한 화면에 모두 보일지, 우선순위 차원만 보이고 나머지는 드릴다운할지

이 문서는 위 결정들을 **하지 않는다.** 목표 4 착수 시 `superpowers:brainstorming`으로 연다.
