## 2. 채택할 미감

- **무채색/저채도 기반** (01, 02, 06) — 색을 신호 전용으로 남길 수 있다. HbO/HbR 발산 컬러맵
  (청↔백↔적), 위험 구간, 임계 초과 차원이 장식과 경쟁하지 않는다. 연구용 대시보드에서 이건
  미감이 아니라 판독성 문제다.
- **랩 리포트 프레이밍** (02) — `FIG. 2A / SESSION 402` 같은 그림 번호·캡션. 교수자가 근거를
  인용하고 논문에 옮기기 쉬워진다.
- **leader line 지표 목록** (02) — 6차원을 좁은 폭에 나란히 놓기 좋다.
- **이상치만 착색** (06) — 91.0%만 주황. 위험 구간 표시 규칙으로 그대로 쓸 수 있다.
- 헤어라인 보더, 큰 여백, small-caps 라벨, 소문자 대형 헤드라인.

## 3. ⚠ 정보 구조는 6종 모두 그대로 쓰면 안 된다

여섯 개 전부 **학습자 본인용 자기 모니터링**이다. 계획서 목표 4는 **교수자용 다인 모니터링**이다.

| 목업 공통 | 계획서 목표 4 |
|---|---|
| 단일 피험자 (`Subject 402`, `USER_ID 8829-X`) | 다수 학습자 동시 + 집단 분포 |
| 1~4개 지표 | **6차원 벡터** (인지부하·주의·피로·몰입·수행정확도·반응지연) |
| `optimal` / `High` — **판정만** | **판정 근거**: "전전두엽 HbO 23% 증가(기여도 0.41), α/θ 저하(0.28), 반응시간 증가(0.18)" |
| XAI 표면 없음 | **SHAP·어텐션 기여도가 화면의 중심** |
| 없음 | 교수전략 제안 + **수용 / 수정 / 거부** (자동 실행 금지) |
| 없음 | 위험 구간 자동 감지, **교수자가 임계치 조정** |

### 가장 위험한 지점

`01`의 `efficiency index 84.2%`, `05`의 `SYNC SCORE 92` 같은 **단일 종합 점수는 폐기된 4채널
집중도 측정기가 하던 바로 그것**이다. `CLAUDE.md` §10이 명시적으로 금지한다 — 1차원 집중도
지수를 6차원 벡터 대용으로 쓰지 말 것. 레이아웃을 그대로 옮기면 폐기한 자리로 되돌아간다.

`optimal`, `High` 같은 판정어도 같은 계열이다. 목표 4의 핵심은 **AI가 왜 그렇게 판단했는지를
교수자가 이해·검증·수정할 수 있게 하는 것**이므로, 근거 없는 판정어는 그 반대 방향이다.

## 4. 미감은 살리고 구조는 바꾸는 매핑

| 목업의 자리 | 대체 |
|---|---|
| `01` 원형 게이지 / `05` SYNC SCORE | 6차원 레이더 또는 6개 스몰멀티플 스파크라인 |
| `02` leader line 4지표 | 그대로 6차원으로 확장 — 이 패턴이 가장 잘 맞는다 |
| `06` `Subject focus distribution` 퍼센트 목록 | **SHAP 기여도 바** (부호 있는 값, 이상치만 착색) |
| `01` `current status: optimal` | 근거 문장 + 트리거된 교수전략 카드 (수용/수정/거부 버튼) |
| `04` 최근 세션 리스트 | 학습자 목록 — 위험 구간 학습자를 상단 고정 |
| `01` 푸터 3분할 (sessions/streak) | 학습자 수 · 위험 학습자 수 · 최근 갱신 시각 |
| `02` `FIG. 2A / SESSION 402` 캡션 | 유지 — 근거 인용 가능성을 높인다 |

## 5. 아직 결정하지 않은 것

- **대시보드 스택** (`CLAUDE.md` §9.2-5): React+FastAPI(WebSocket) vs Streamlit/Dash. 미확정.
- 실시간성 요구 수준 — 계획서는 "실시간 시각화"라고만 명시. 갱신 주기 미정.
- 한 화면에 학습자 몇 명까지 표시할지.
- 6차원을 한 화면에 모두 보일지, 우선 차원만 보이고 나머지는 드릴다운할지.

이 문서는 위 결정들을 **하지 않는다.** 목표 4 착수 시 `superpowers:brainstorming`으로 연다.
